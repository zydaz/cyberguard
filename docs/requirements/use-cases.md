# CyberGuard — Use Cases Specification

## 1. Introduction

This document describes the main use cases of the CyberGuard security monitoring platform.

The purpose is to identify how external actors interact with the system and define the expected behavior before implementation.

## 2. System Actors

### Security Analyst (SOC Analyst)

A security professional responsible for monitoring security alerts, investigating suspicious activities, and managing security incidents.

### External Application

An external system that generates and sends security events to CyberGuard for analysis.

## 3. Use Cases

| ID | Actor | Use Case | Description |
|---|---|---|---|
| UC-01 | SOC Analyst | Authenticate | Log in securely to access CyberGuard. |
| UC-02 | SOC Analyst | View Security Alerts | View alerts generated by the detection system. |
| UC-03 | SOC Analyst | Investigate Suspicious Events | Examine event details and related security information. |
| UC-04 | SOC Analyst | Manage Alerts | Update the investigation status of security alerts. |
| UC-05 | External Application | Submit Security Events | Send security events to CyberGuard for processing. |

## 4. Example Use Case: UC-02

**Name:** View Security Alerts

**Primary Actor:** SOC Analyst

**Preconditions:**
- The analyst is authenticated.
- The analyst has permission to view alerts.

**Main Flow:**
1. The analyst accesses the security alerts section.
2. CyberGuard retrieves the available alerts.
3. CyberGuard displays the alerts.
4. The analyst selects an alert to view its details.

**Postconditions:**
- The analyst has access to the relevant alert information.
- No alert status is modified by simply viewing it.

## 5. Scope

The first version of CyberGuard will focus on event collection, rule-based detection, alert visualization, and basic alert management.

Advanced machine learning capabilities are outside the scope of the initial version.
