# CyberGuard

**Security Event Monitoring & Threat Detection Platform**

## Overview

CyberGuard is a cybersecurity project designed to centralize, analyze, and monitor security events generated by external applications.

The project aims to help security analysts identify suspicious activities, investigate incidents, and maintain a history of security events.

## Objectives

- Centralize security events from external applications.
- Detect suspicious activities using configurable rules.
- Generate and manage security alerts.
- Provide a dashboard for security monitoring.
- Maintain event history to support security investigations.

## Planned Tech Stack

- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL
- **Frontend:** React
- **Security:** Spring Security
- **Testing:** JUnit, Mockito
- **DevOps:** Docker, GitHub Actions

*The technology choices may evolve during the design phase.*
